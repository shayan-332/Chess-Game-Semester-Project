# CHESS GAME - OOP Semester Project

## Description
A two-player chess game played in console. White moves first (UPPERCASE letters), Black moves second (lowercase letters).

## How to Play
- Enter move as: e2 e4
- First piece gets captured automatically
- Game ends at checkmate or stalemate

## OOP Concepts Used
- Inheritance (pieces inherit from base class)
- Polymorphism (virtual functions for moves)
- Encapsulation (private data members)
- Composition (board has pieces)
